Imagina que quieres sumar los números del 1 al 100. ¿Escribirías 100 líneas? Un ciclo repite un bloque de instrucciones muchas veces por ti. Pero para que la repetición sirva, necesitamos variables que "recuerden" algo de una vuelta a la siguiente: el contador y el acumulador.

El patrón que verás toda la carrera:
MomentoDóndeQué se hace
1. InicializarAntes del ciclocontador <- 0 · suma <- 0 · producto <- 1
2. ActualizarDentro del ciclocontador <- contador + 1 · suma <- suma + x
3. UsarDespués del cicloEscribir suma

🔢 Variable contador

Una variable que aumenta en una cantidad fija (casi siempre +1) cada vez que ocurre algo. Sirve para responder "¿cuántas veces…?".

Sus tres momentos:
  1. Inicializar antes del ciclo, en 0: contador <- 0
  2. Actualizar dentro, con paso fijo: contador <- contador + 1
  3. Usar el valor final después del ciclo

Ejemplo — Contar cuántos números son pares

Algoritmo ContarPares
    Definir i, n, contador Como Entero
    Leer n
    contador <- 0                     // inicializar
    Para i <- 1 Hasta n Con Paso 1 Hacer
        Si i MOD 2 = 0 Entonces
            contador <- contador + 1  // +1 fijo
        FinSi
    FinPara
    Escribir "Cantidad de pares: ", contador
FinAlgoritmo

Prueba: n=10 → 5 · n=7 → 3 · n=1 → 0.

🐍 En Python
Igual, y suele abreviarse con +=: 
contador = 0
contador = contador + 1   # o, más corto:  contador += 1

➕ Variable acumulador

Una variable que va juntando valores que cambian en cada vuelta. Sirve para responder "¿cuál es el total / la suma / el producto?".

Ejemplo — Sumar los primeros N números

Algoritmo SumarNumeros
    Definir i, n, suma Como Entero
    Leer n
    suma <- 0                     // inicializar acumulador
    Para i <- 1 Hasta n Con Paso 1 Hacer
        suma <- suma + i         // valor VARIABLE (i)
    FinPara
    Escribir "La suma es: ", suma
FinAlgoritmo

Prueba: N=5 → 15 · N=10 → 55 · N=100 → 5050.

⚠️ Inicialización: si vas a sumar, empieza en 0 (sumar 0 no cambia nada). Si vas a multiplicar, empieza en 1 (multiplicar por 1 no cambia nada). Un producto que empiece en 0 daría siempre 0.

🐍 En Python
suma = 0
suma = suma + i        # o:  suma += i
# producto (multiplicativo):
producto = 1
producto = producto * i   # o:  producto *= i

🔁 Ciclo FOR — la estructura Para

Repite un bloque un número conocido de veces. Tiene una variable de control que va desde un inicio hasta un fin, avanzando con un paso. El ciclo mismo la inicializa, la compara y la aumenta: ¡tú no la tocas!

Para variable <- inicio Hasta fin Con Paso salto Hacer
    // instrucciones que se repiten
FinPara
  • inicio: valor con el que arranca la variable.
  • fin: último valor — en PSeInt, Hasta N incluye a N.
  • paso (Con Paso): cuánto sube cada vuelta (si es 1, puede omitirse).

Ejemplo mínimo — Mostrar del 1 al 5

Para i <- 1 Hasta 5 Con Paso 1 Hacer
    Escribir i
FinPara
// Salida: 1 2 3 4 5

¿Cómo funciona por dentro? (diagrama)

🐍 En Python
El Para es for con range(inicio, fin, paso). ¡Ojo! el límite superior de range NO se incluye: para llegar hasta N se escribe range(1, N+1). 
for i in range(1, 6):     # 1,2,3,4,5 (el 6 NO entra)
    print(i)
Diferencia clave: en PSeInt Hasta 5 sí incluye el 5; en Python range(1,6) llega hasta 5 (excluye el 6).
