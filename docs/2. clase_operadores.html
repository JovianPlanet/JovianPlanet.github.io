¿Qué es un operador?

Un operador es un símbolo que le dice al computador que realice una operación sobre unos valores llamados operandos. El resultado es siempre un nuevo valor.

   5     +     3        →      8
operando  operador  operando       resultado
Los agrupamos en tres familias según lo que producen:
  • Aritméticos → producen un número (sumar, dividir…).
  • Relacionales → producen Verdadero / Falso (comparan).
  • Lógicos → combinan Verdadero/Falso con y / o / no.

Aritméticos

Hacen cálculos numéricos. La única trampa para principiantes es la división: separar la división con decimales de la división entera y el residuo (módulo).

7 /  2  → 3.5   # división real
7 // 2  → 3     # división entera
7 %  2  → 1     # módulo (residuo)

Relacionales

Comparan dos valores y siempre devuelven Verdadero o Falso. Son la base de las decisiones que verás con el Si… Entonces.

¡Error clásico! = asigna (guardar un valor); == compara (preguntar si son iguales). En Python, C++ y Java comparar es siempre ==.

Lógicos

Conectan condiciones como en el lenguaje natural:

Y (AND): verdadero solo si ambas son verdaderas — "tengo dinero y hay boletos".
O (OR): verdadero si al menos una lo es — "es sábado o es domingo".
NO (NOT): invierte el valor — "no está lloviendo".

Precedencia: ¿quién va primero?

Con varios operadores, el computador sigue un orden de prioridad (como en matemáticas: primero multiplicas, luego sumas).

PrioridadOperadoresGrupo
1 (alta)( )Paréntesis
2**Potencia
3+x -xSigno
4* / // %Multiplicativos
5+ -Aditivos
6< <= > >= == !=Relacionales
7notNegación
8andConjunción
9 (baja)orDisyunción
Regla de oro: primero lo aritmético, luego se compara, y al final se razona con lógicos (not → and → or). Los paréntesis siempre mandan.
