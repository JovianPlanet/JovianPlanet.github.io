Un programa también decide

Todos los días tomamos decisiones con una condición: si sí, hago una cosa; si no, otra. Un programa hace lo mismo: evalúa una condición (que da True o False) y elige qué instrucciones ejecutar.

🛵 App de domiciliosSi el restaurante está abierto → deja pedir. Si no → muestra "Cerrado".
🔐 Inicio de sesiónSi la clave es correcta → entra. Si no → "Clave incorrecta".
🔋 CelularSi la batería baja de 20 % → activa el ahorro de energía.

Las 4 estructuras de hoy

ifAlgo se hace solo si se cumple la condición.
if lluvia >= 60:
    print("☂")
if-elseHay dos caminos posibles.
if cupos > 0:
    print("Entra")
else:
    print("Lleno")
if-elif-elseHay tres o más caminos.
if ica <= 50:
    ...
elif ica <= 100:
    ...
else:
    ...
match-caseComparas un valor con opciones exactas.
match tecla:
    case "w":
        ...
    case _:
        ...

🔀 Condicional simple: if

if ejecuta un bloque solo si la condición es True. Si es False, el bloque se omite y el programa continúa. Úsalo para decisiones de "sí o no".

ifPalabra reservada, en minúsculas.
condiciónExpresión que da True o False.
:Los dos puntos son obligatorios.
sangríaLas líneas con 4 espacios forman el bloque.
sin sangríaYa no pertenece al if: se ejecuta siempre.
lluvia.py 
prob = int(input("Probabilidad de lluvia (%): "))
if prob >= 60:
    print("☂ Lleva paraguas")       # dentro del if
    print("🧥 Y una chaqueta")      # dentro del if
print("Que tengas un buen día")    # fuera: se ejecuta siempre
probprob >= 60Salida
80True☂ Lleva paraguas · 🧥 Y una chaqueta · Que tengas un buen día
60Truelas tres líneas (60 es el caso límite)
30FalseQue tengas un buen día
Sangría: usa siempre 4 espacios (convención PEP 8) y la misma en todo el bloque. Mezclar tabulaciones y espacios produce TabError.

Condicional doble: if-else

if-else elige uno de dos caminos: True → bloque del if; False → bloque del else. Siempre se ejecuta exactamente uno, nunca ambos. El else no lleva condición, va al mismo nivel que su if y lleva :.

parqueadero.py 
cupos = int(input("Cupos disponibles: "))
if cupos > 0:
    print("🚗 Puedes entrar")
    print(f"Quedarán {cupos - 1} cupos")
else:
    print("⛔ Parqueadero lleno")
🎯 Prueba siempre el caso límite. Aquí es cupos = 0: ahí se nota si escribiste >= cuando debías usar >.

Bonus: if-else en una línea

Cuando cada camino solo asigna un valor, puedes escribirlo en una línea (expresión condicional):

estado = "Hay cupo" if cupos > 0 else "Lleno"

Se lee: estado vale "Hay cupo" si cupos > 0; si no, vale "Lleno".

🪜 Condicional múltiple: if-elif-else

Evalúa varias condiciones en orden, de arriba hacia abajo. elif prueba una nueva condición solo si las anteriores fueron False. Se ejecuta solo el primer bloque cuya condición sea True: las demás ya no se revisan. El else es opcional y es el caso por defecto.

calidad_aire.py 
ica = int(input("Índice de calidad del aire: "))
if ica <= 50:
    print("🟢 Buena")
elif ica <= 100:
    print("🟡 Aceptable")
elif ica <= 150:
    print("🟠 Dañina para grupos sensibles")
else:
    print("🔴 Dañina para la salud")
icaPrimera condición TrueSalida
35ica <= 50🟢 Buena
100ica <= 100🟡 Aceptable
101ica <= 150🟠 Dañina para grupos sensibles
220ninguna → else🔴 Dañina para la salud
¿Por qué elif ica <= 100 y no elif 50 < ica <= 100? Porque si llegamos a ese elif es que ica <= 50 ya fue False: ¡ya sabemos que es mayor que 50!

🧩 Ordena las condiciones

Enunciado: una tienda da descuento según el valor de la compra: 500000 o más → 20 %, 200000 o más → 10 %, 100000 o más → 5 %, si no, 0 %. Toca las condiciones para ponerlas en el orden correcto y pulsa Comprobar: el juego probará tu programa con varias compras.

📐 Regla: con rangos "de … o más", ordena de la condición más exigente a la menos exigente. Si pones primero la más fácil de cumplir, atrapa a todos y las demás nunca se revisan.

🪆 Condicionales anidados

Un condicional anidado está dentro del bloque de otro. Se usa cuando una condición solo tiene sentido si otra ya se cumplió. La sangría muestra qué está dentro de qué.

biblioteca.py 
es_estudiante = input("¿Estudiante? (s/n): ") == "s"
multas = int(input("Multas pendientes: "))
if es_estudiante:
    if multas == 0:                         # solo se pregunta si es estudiante
        print("📚 Puedes llevar hasta 3 libros")
    else:
        print(f"💸 Primero paga tus {multas} multas")
else:
    print("🪑 Solo puedes consultar en sala")

Fíjate que es_estudiante ya es un bool: la comparación == "s" da True o False, por eso basta con if es_estudiante:.

¿Anidar o usar and?

anidado.py
if hora >= 6:
    if hora < 22:
        print("Gimnasio abierto")
con_and.py
if hora >= 6 and hora < 22:
    print("Gimnasio abierto")
encadenado.py
if 6 <= hora < 22:
    print("Gimnasio abierto")
🧠 Los tres hacen lo mismo. Python permite encadenar comparaciones como en matemáticas: 6 <= hora < 22. Si el anidamiento pasa de 2 o 3 niveles, piensa en and / or o en elif: tu código será más fácil de leer. Anida cuando cada nivel tiene su propio else con un mensaje distinto (como en la biblioteca).

🎛️ Estructura match-case

match-case compara un valor con varios patrones y ejecuta el primero que coincida. Es parecido a Segun de PSeInt. Disponible desde Python 3.10.

case _:Caso por defecto (como else o De Otro Modo).
case "w" | "arriba":Agrupa varios valores con | ("o").
case n if n > 100:Guarda: el caso solo aplica si se cumple la condición.
Sin breakA diferencia del switch de C o Java: solo se ejecuta un caso.
dron.py 
comando = input("Comando: ")
match comando:
    case "w" | "arriba":
        print("⬆️ El dron sube")
    case "s" | "abajo":
        print("⬇️ El dron baja")
    case "x":
        print("🛬 Aterrizando")
    case _:
        print("❓ Comando desconocido")

¿Cuál uso?

SituaciónMejor opción
Valores exactos (1, 2, 3… o "w", "s", "x")match-case
Rangos (ica <= 50, nota >= 4.0)if-elif-else
Condiciones combinadas (and, or)if-elif-else
