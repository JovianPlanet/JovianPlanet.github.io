Del pseudocódigo a un lenguaje real

Hasta ahora diseñaste algoritmos en pseudocódigo (PSeInt). Un lenguaje de programación es un conjunto formal de reglas e instrucciones que permite decirle a una computadora cómo resolver un problema. Desde hoy, tus algoritmos se escriben en Python y la computadora los ejecuta de verdad.

Variables y asignación

El signo = asigna: guarda el valor de la derecha en la variable de la izquierda (como <- en PSeInt). En Python no declaras el tipo: lo decide el valor.

ciudad = "Medellín"      # str
estudiantes = 32         # int
temperatura = 24.5       # float
print(type(temperatura))  # <class 'float'>
Reglas para los nombres: solo letras, números y guion bajo _; no pueden empezar con número, no llevan espacios ni símbolos (-, $…) y no pueden ser palabras reservadas (for, if, class, True…). Convención: snake_case → minúsculas y guion bajo: precio_final.

⌨️ Estructura secuencial: Entrada → Proceso → Salida

Las instrucciones se ejecutan en orden, una tras otra, sin decisiones ni repeticiones. En Python no declaras variables: se crean cuando les asignas un valor.

Entrada de datos: input()

ciudad = input("¿En qué ciudad vives? ")
hermanos = int(input("¿Cuántos hermanos tienes? "))

input() siempre devuelve texto (str). Para calcular, conviértelo con int() o float(). El mensaje entre paréntesis es lo que ve el usuario antes de escribir.

Ejemplo completo: recibo de la cafetería

recibo.py 
# Entrada
producto = input("Producto: ")
precio = float(input("Precio unitario: "))
cantidad = int(input("Cantidad: "))
# Proceso
subtotal = precio * cantidad
descuento = subtotal * 0.10
total = subtotal - descuento
# Salida
print(f"{cantidad} x {producto}")
print(f"Subtotal: {subtotal:.2f}")
print(f"Descuento: {descuento:.2f}")
print(f"Total a pagar: {total:.2f}")

🐞 Caza el error

Equivocarse es parte de programar. Lo importante es leer el mensaje: Python te dice el tipo de error y la línea.

ErrorEjemploQué significa
SyntaxErrorprint("Hola)Está mal escrito: faltan comillas, paréntesis o los dos puntos :.
NameErrorPrint("Hola")Un nombre que no existe: mal escrito (¡mayúsculas!) o variable sin crear.
TypeError"5" + 3Operación entre tipos incompatibles. ¿Olvidaste int() al leer?
ValueErrorint("3.5")El tipo es correcto pero el valor no se puede convertir.
Clásico de la clase: este programa falla. ¿Por qué? 
edad = input("¿Cuántos años tienes? ")
print("El próximo año tendrás", edad + 1)
Ver explicación

input() devuelve texto: "17" + 1 mezcla str con int → TypeError. Solución: convierte al leer → edad = int(input("¿Cuántos años tienes? ")).
