🛠️ Definir y llamar una función

bienvenida.py 
def bienvenida(nombre):
    mensaje = f"¡Hola, {nombre}! Bienvenido al curso"
    return mensaje

texto = bienvenida("Laura")
print(texto)
print(bienvenida("Mateo"))
defPalabra reservada: "defino una función".
bienvenidaEl nombre: un verbo en snake_case (calcular_iva, es_par).
(nombre)Los parámetros: sus entradas. Pueden ser cero o varios.
: y sangríaEl cuerpo: lo que hace la función.
returnEntrega el resultado a quien la llamó (opcional).

¿Qué pasa cuando se llama?

1Python lee el def y guarda la función. No ejecuta su cuerpo todavía.
2Al llegar a bienvenida("Laura"), el programa salta a la función: nombre vale "Laura".
3Se ejecuta el cuerpo y return devuelve el mensaje.
4El programa regresa a donde estaba: texto recibe el mensaje y sigue.

↩️ Parámetros y return

ParámetroLa variable que aparece en la definición: def area(base, altura):
ArgumentoEl valor que se envía en la llamada: area(5, 3). Se copia en el parámetro de la misma posición.
returnEntrega un valor y termina la función de inmediato. Sin return, la función devuelve None.
precio.py 
def precio_final(precio, descuento):
    con_descuento = precio * (1 - descuento / 100)
    return con_descuento * 1.19

total = precio_final(100000, 20)                 # se guarda en una variable
print(f"Pagas: {total:.2f}")
print(f"Dos unidades: {2 * precio_final(100000, 20):.2f}")   # se usa en una operación

¿print o return?

printreturn.py
def doble_print(x):
    print(x * 2)          # muestra, pero no devuelve

def doble_return(x):
    return x * 2          # devuelve, pero no muestra

a = doble_print(5)
b = doble_return(5)
print("a =", a, "| b =", b)
10
a = None | b = 10
print le muestra algo a la persona; return le entrega un valor al programa para que lo siga usando. Una función que solo hace print devuelve None: no puedes sumarlo, compararlo ni guardarlo.

Funciones que devuelven True o False

votar.py 
def es_mayor_de_edad(edad):
    return edad >= 18                # la comparación ya es True o False

for edad in [15, 18, 32, 17]:
    if es_mayor_de_edad(edad):       # se usa directo como condición
        print(edad, "→ puede votar")
    else:
        print(edad, "→ aún no")
Nombra las funciones booleanas como una pregunta: es_par, es_primo, tiene_descuento, fecha_valida.

🌍 Ámbito de las variables

📦 LocalSe crea dentro de la función (incluidos sus parámetros). Solo existe mientras la función se ejecuta y desaparece al terminar.
🌍 GlobalSe crea fuera de las funciones. Las funciones pueden leerla.
ambito.py 
tasa_iva = 0.19                      # global

def con_iva(precio):
    total = precio * (1 + tasa_iva)  # total es local
    return total

print(con_iva(1000))
print(total)                         # ¿existe total aquí afuera?
1190.0
NameError: name 'total' is not defined

Mismo nombre, distinta variable

sombra.py
puntos = 10

def jugar():
    puntos = 99              # crea OTRA variable, local
    print("Dentro:", puntos)

jugar()
print("Fuera:", puntos)
Dentro: 99
Fuera: 10
La global no cambia. Si una función necesita un dato, lo correcto es recibirlo como parámetro; si produce un resultado, entregarlo con return. Así cada función es una caja independiente.

🎛️ Formas de pasar argumentos

pedido.py 
def pedido(producto, cantidad, precio, envio=5000):    # envio tiene valor por defecto
    total = cantidad * precio + envio
    return f"{cantidad} x {producto}: ${total}"

print(pedido("empanada", 6, 2500))                       # posicionales; envio = 5000
print(pedido("arepa", 3, 4000, envio=0))                 # posicionales + uno por nombre
print(pedido(precio=12000, producto="pizza", cantidad=2))  # por nombre, en cualquier orden
6 x empanada: $20000
3 x arepa: $12000
2 x pizza: $29000
FormaCómo se escribeRegla
Posicionalpedido("arepa", 3, 4000)cada valor va al parámetro de la misma posición: el orden importa
Por nombrepedido(cantidad=3, producto="arepa", precio=4000)el orden no importa; el nombre debe existir (si no: TypeError)
Por defectodef pedido(…, envio=5000):si no lo envías, usa ese valor. Van al final de la definición (si no: SyntaxError)
Combinadaspedido("arepa", 3, 4000, envio=0)al llamar, primero los posicionales y después los nombrados

Cualquier cantidad de argumentos: *args

args.py 
def promedio(*notas):              # notas agrupa TODOS los valores recibidos
    if len(notas) == 0:
        return 0
    suma = 0
    for n in notas:                # se recorren con un for
        suma += n
    return suma / len(notas)

print(round(promedio(4.5, 3.0, 5.0), 2))
print(round(promedio(2.8, 3.6), 2))
print(promedio())
Así funciona print(): recibe cualquier cantidad de valores. Existe también **kwargs (cualquier cantidad de argumentos por nombre); lo usarás cuando veas diccionarios.
