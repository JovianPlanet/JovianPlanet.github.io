¿Por qué repetir?

Muchos problemas hacen lo mismo muchas veces: liquidar el pago de cada empleado, revisar cada letra de una contraseña, calcular la cuota de cada mes de un crédito. Copiar la misma instrucción cien veces no es programar: para eso existen los ciclos (también llamados bucles o loops).

🧾 NóminaPara cada uno de los 40 empleados: calcula su salario y súmalo al total de la empresa.
🔐 ContraseñaPara cada carácter: ¿es mayúscula? ¿es número? Al final decide si la clave es segura.
💳 CréditoPara cada mes del 1 al 12: calcula el interés, la cuota y el saldo pendiente.
sin_ciclo.py
print("Empleado 1: pago registrado")
print("Empleado 2: pago registrado")
print("Empleado 3: pago registrado")
# ... 36 líneas más ...
print("Empleado 40: pago registrado")
con_ciclo.py
for i in range(1, 41):
    print(f"Empleado {i}: pago registrado")

2 líneas en lugar de 40. Y si mañana son 400 empleados, solo cambias un número.

Anatomía del for

forPalabra reservada: "para cada…".
variableToma un valor distinto en cada vuelta (aquí i).
in"…en…". Obligatoria.
secuenciaDe dónde salen los valores: range(), un texto o una lista.
: y sangríaLas líneas con 4 espacios son el cuerpo: se repiten en cada vuelta.
for i in range(1, 6):          # i toma 1, 2, 3, 4, 5
    print(f"Vuelta {i}")       # cuerpo: se repite 5 veces
print("Terminó el ciclo")      # sin sangría: se ejecuta una sola vez, al final

¿for o while? Usa for cuando sabes cuántas vueltas habrá o cuando recorres una colección (un texto, una lista). Cuando la cantidad de vueltas depende de algo que ocurre durante la ejecución, usarás while (próxima lección).

🎯 La función range()

range(inicio, parada, paso) genera una secuencia de enteros. El ciclo da una vuelta por cada número generado.

inicioPrimer valor. Si lo omites, vale 0.
paradaObligatoria. Nunca se incluye: el último valor queda antes de ella.
pasoCuánto cambia en cada vuelta. Si lo omites, vale 1. Puede ser negativo, nunca 0.
EscribesGeneraVueltas
range(4)0 1 2 34
range(3, 8)3 4 5 6 75
range(5, 26, 5)5 10 15 20 255
range(9, 0, -3)9 6 33
range(6, 2)(nada)0 — el paso es +1 y ya empieza después de la parada

➕ Contadores y acumuladores

Dentro de un ciclo casi siempre necesitas recordar algo de las vueltas anteriores. Para eso hay dos patrones:

ContadorAcumulador
¿Qué guarda?Cuántas veces ocurrió algoLa suma (o el producto) de valores que cambian
¿Cómo cambia?Una cantidad fija: c += 1Un valor que cambia: total += precio
¿Con qué empieza?00 si suma (0 + x = x) · 1 si multiplica (1 × x = x)
¿Dónde se crea?Antes del ciclo. Si lo creas dentro, se reinicia en cada vuelta.

Contador: días activos de la semana

Un reloj inteligente considera "activo" un día con 8000 pasos o más. ¿Cuántos días activos tuviste?

pasos.py 
dias_activos = 0                       # contador: empieza en 0
for dia in range(1, 8):                # 7 vueltas: días 1 a 7
    pasos = int(input(f"Pasos del día {dia}: "))
    if pasos >= 8000:
        dias_activos += 1              # solo cuenta cuando ocurre el evento
print(f"Días activos: {dias_activos} de 7")

Acumulador de producto: potencia sin usar **

potencia.py 
base = int(input("Base: "))
exponente = int(input("Exponente: "))
resultado = 1                          # acumulador de producto: empieza en 1
for _ in range(exponente):             # _ : no necesito el valor de la vuelta
    resultado *= base
print(f"{base}^{exponente} = {resultado}")
Reto mental: ¿qué pasaría si resultado empezara en 0? (Pista: 0 multiplicado por cualquier cosa…)

🔤 Recorrer textos y listas

El for no solo cuenta números: puede recorrer cualquier secuencia. Con un texto, la variable toma un carácter por vuelta; con una lista, un elemento por vuelta. No necesitas índices.

letras.py
for letra in "Lógica":
    print(letra, end=" ")
L ó g i c a
materias.py
materias = ["Lógica", "Cálculo", "Física"]
for m in materias:
    print("Estudio", m)
Estudio Lógica
Estudio Cálculo
Estudio Física
end=" " cambia lo que print pone al final: en vez de saltar de línea, deja un espacio. Así varias vueltas escriben en la misma línea. Un print() vacío hace el salto cuando lo necesites.

Ejemplo: ¿mi contraseña es segura?

clave.py 
clave = input("Crea una contraseña: ")
mayusculas = 0
digitos = 0
for c in clave:                        # un carácter por vuelta
    if c.isupper():                    # ¿es letra mayúscula?
        mayusculas += 1
    elif c.isdigit():                  # ¿es un dígito?
        digitos += 1
if len(clave) >= 8 and mayusculas >= 1 and digitos >= 1:
    print("🔒 Contraseña segura")
else:
    print("⚠️ Débil: usa 8 o más caracteres, una mayúscula y un número")

🧱 Ciclos anidados

Un ciclo dentro de otro. Por cada vuelta del ciclo externo, el ciclo interno se ejecuta completo, desde el principio. Es como un reloj: por cada hora pasan los 60 minutos.

sala.py — los puestos de una sala de cine 
for fila in "ABC":                     # externo: 3 vueltas (A, B, C)
    for asiento in range(1, 6):        # interno: 5 vueltas por cada fila
        print(f"{fila}{asiento}", end=" ")
    print()                            # dentro del externo, fuera del interno: salto de línea
A1 A2 A3 A4 A5
B1 B2 B3 B4 B5
C1 C2 C3 C4 C5
¿Cuántas veces se ejecuta el print interno? vueltas del externo × vueltas del interno = 3 × 5 = 15. Fíjate en la sangría del print() vacío: si lo corres 4 espacios a la derecha, el salto de línea ocurre después de cada asiento.

El interno puede depender del externo

triangulo.py 
n = int(input("Altura: "))
for i in range(1, n + 1):
    for j in range(i):                 # en la fila i hay i asteriscos
        print("*", end="")
    print()
