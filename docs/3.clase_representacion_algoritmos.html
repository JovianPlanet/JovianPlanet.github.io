¿Qué es un algoritmo?

Un algoritmo es una secuencia finita y ordenada de pasos que resuelve un problema. La misma idea puede escribirse de tres formas, de lo más humano a lo más formal:

Lenguaje naturalhablamos
→
Pseudocódigosemi-código
→
Diagrama de flujodibujamos
→
Código realPython, C++…

Lenguaje natural

Es describir el algoritmo con nuestras propias palabras, como se lo explicaríamos a otra persona. No tiene reglas de sintaxis.

Ejemplo — Ganancia de un comerciante:
"Le pregunto a qué precio compró y a qué precio vendió el producto. Le resto al precio de venta el de compra para obtener la ganancia. Finalmente, le muestro cuánto ganó."

Ventajas y límites

✅ Ventajas⚠️ Límites
Cualquiera lo entiende, sin saber programarEs ambiguo: una frase se interpreta de varias formas
Rápido para pensar la idea inicialNo marca bien el orden ni las decisiones
No exige aprender símbolos ni reglasDifícil de traducir directo a código
Por eso existen el pseudocódigo y el diagrama de flujo: quitan la ambigüedad y acercan la idea al código.

🎲 Cazadores de ambigüedad

Lee esta instrucción. ¿De cuántas formas distintas se puede entender?

"Suma los números y divídelos entre 2."

  • ¿"Los números" son dos, o una lista completa? (¿es un promedio?)
  • ¿Se divide la suma entre 2, o cada número entre 2?
  • ¿En qué orden ocurre? La frase no lo fija.

Conclusión: el lenguaje natural es cómodo pero ambiguo. Necesitamos algo más preciso → el pseudocódigo.

Pseudocódigo (con PSeInt)

Descripción paso a paso de un algoritmo, en lenguaje simple pero con estructura parecida a un código. Es para que lo entienda un humano; no lo ejecuta directamente la máquina y no usa la sintaxis exacta de ningún lenguaje real (pseudo = falso).

Características: combina lenguaje natural con instrucciones tipo programación · no es estricto con la sintaxis, pero sí ordenado y sin ambigüedad · sirve para planear la lógica antes de programar y reducir errores.

Estructura: Inicio/FinDeclarar variablesEntradaProcesoSalida

Ejemplo A — Ganancia del comerciante

Algoritmo GananciaComerciante
    Definir precio_compra, precio_venta, ganancia Como Real
    Escribir "Ingrese el precio de compra:"
    Leer precio_compra
    Escribir "Ingrese el precio de venta:"
    Leer precio_venta
    ganancia <- precio_venta - precio_compra
    Escribir "La ganancia es: ", ganancia
FinAlgoritmo

Ejemplo B — Sumar dos números

Algoritmo SumarDosNumeros
    Definir num1, num2, suma Como Real
    Escribir "Ingrese el primer número:"
    Leer num1
    Escribir "Ingrese el segundo número:"
    Leer num2
    suma <- num1 + num2
    Escribir "La suma es: ", suma
FinAlgoritmo

Representación gráfica de un algoritmo con símbolos estándar unidos por líneas de flujo. Se lee siguiendo las flechas, casi siempre de arriba hacia abajo.
