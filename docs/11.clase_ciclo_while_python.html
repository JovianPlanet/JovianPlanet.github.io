Repetir mientras algo sea cierto

Con for sabías de antemano cuántas vueltas habría. Pero muchas veces no lo sabes: ¿cuántas veces escribirá mal la contraseña el usuario? ¿cuántos meses tardarás en reunir para el viaje? ¿cuántos productos pasará el cajero? Para eso está while: repite un bloque mientras una condición sea True.

🔐 ValidarMientras el PIN no tenga 4 dígitos, vuelve a pedirlo.
💰 AhorrarMientras el saldo no llegue a la meta, suma un mes más.
🛒 RegistrarMientras el cajero no escriba "fin", sigue sumando productos.

Anatomía del while

regresiva.py
n = int(input("¿Desde qué número? "))  # 1. valor inicial
while n > 0:                   # 2. se revisa antes de cada vuelta
    print(n)
    n -= 1                     # 3. el cuerpo cambia n
print("🚀 ¡Despegue!")         # al salir del ciclo

Las 3 partes de todo while: (1) la variable de la condición tiene un valor antes de empezar, (2) la condición se revisa antes de cada vuelta (si es False desde el principio, el cuerpo no se ejecuta ni una vez) y (3) algo dentro del cuerpo la cambia. Si falta la parte 3, tienes un ciclo infinito.

Ejemplo: validar un dato

pin.py 
pin = input("PIN de 4 dígitos: ")
while len(pin) != 4 or not pin.isdigit():     # mientras esté MAL…
    print("PIN inválido")
    pin = input("PIN de 4 dígitos: ")         # …vuelve a pedirlo
print("PIN registrado ✔")

Ejemplo: ¿cuántos meses para la meta?

ahorro.py 
saldo = float(input("Ahorro inicial: "))
meta = float(input("Meta: "))
meses = 0
while saldo < meta:
    saldo *= 1.05          # el ahorro rinde 5 % cada mes
    meses += 1             # contador de vueltas
print(f"Meta alcanzada en {meses} meses: {saldo:.2f}")

♾️ Ciclos infinitos

Un ciclo infinito es un while cuya condición nunca se vuelve False. Hay dos tipos:

😱 Accidental (un error)

i = 1
while i <= 5:
    print("Vuelta", i)
# ¡olvidamos i += 1!

i siempre vale 1: imprime "Vuelta 1" para siempre. En tu computador se detiene con Ctrl + C. En el laboratorio de esta lección, Python lo detecta y te avisa.

😎 Intencional (un patrón)

while True:
    cmd = input("Comando: ")
    if cmd == "salir":
        break              # la única salida
    print(f"Ejecutando «{cmd}»…")
print("Sesión cerrada")

while True se usa a propósito en menús, juegos y servidores, que deben repetirse hasta que el usuario decida salir. La salida es un break.

Las 4 causas más comunes de un ciclo infinito accidental: (1) olvidar actualizar la variable de control, (2) actualizarla en la dirección equivocada (i += 1 cuando la condición es i > 0), (3) usar != con un valor que nunca se alcanza exacto (x += 2 nunca llega a 10 si empieza en 1), y (4) un continue que se salta la actualización.

✋ break, continue y else

breakSale del ciclo de inmediato. Lo que quedaba del cuerpo y las vueltas pendientes no se ejecutan.
continueTermina solo esta vuelta y salta a la siguiente (en un while, vuelve a revisar la condición).
else del cicloSe ejecuta cuando el ciclo termina normalmente, es decir, sin break.

break: el menú de comandos

comandos.py 
while True:
    cmd = input("Comando (salir para terminar): ")
    if cmd == "salir":
        break                            # ← sale del ciclo
    print(f"Ejecutando «{cmd}»…")
print("Sesión cerrada")

continue: saltar los productos agotados

agotados.py 
for codigo in range(1, 8):
    stock = int(input(f"Stock del producto {codigo}: "))
    if stock == 0:
        continue          # agotado: salta al siguiente producto
    print(f"Producto {codigo}: {stock} unidades listas para despacho")

else: ¿encontré un divisor?

divisor.py 
n = int(input("Número (mayor que 1): "))
d = 2
while d * d <= n:                    # basta probar hasta la raíz cuadrada
    if n % d == 0:
        print(f"{n} = {d} × {n // d}: NO es primo")
        break                        # encontré un divisor: no sigo buscando
    d += 1
else:                                # solo si el while terminó SIN break
    print(f"{n} es primo")
Prueba con 91 (= 7 × 13), con 97 y con 1. ¿Qué pasa con 1? 2 * 2 <= 1 es False: el ciclo no da ninguna vuelta, no hay break… y el else dice que 1 es primo. Valida los datos antes del ciclo.

🚩 Centinela y bandera

Centinela: "escribe X para terminar"

Un centinela es un valor acordado que avisa que ya no hay más datos. Se usa cuando el usuario ingresa una serie de datos de tamaño desconocido. Debe ser un valor que nunca aparezca en los datos reales (y nunca se procesa como dato).

peaje.py — centinela "fin" 
total = 0
vehiculos = 0
tarifa = input("Tarifa (fin para terminar): ")     # 1. lectura ANTES del ciclo
while tarifa != "fin":                              # 2. ¿llegó el centinela?
    total += int(tarifa)                            # 3. procesar el dato
    vehiculos += 1
    tarifa = input("Tarifa (fin para terminar): ")  # 4. leer el siguiente, al FINAL
print(f"{vehiculos} vehículos · recaudo {total}")
if vehiculos > 0:                                   # evita dividir entre 0
    print(f"Promedio por vehículo: {total / vehiculos:.2f}")
Patrón "leer – revisar – procesar – leer": se lee antes del ciclo y otra vez al final del cuerpo. Así, cuando llega el centinela, la condición lo detecta antes de procesarlo.

Bandera: "¿ya ocurrió?"

Una bandera (flag) es una variable booleana que indica si algo ya pasó: encontrado / no encontrado, éxito / fracaso. Empieza en un valor y cambia cuando ocurre el evento. Es útil cuando el ciclo tiene varias razones para terminar.

clave.py — bandera acceso 
CLAVE = "lp1-2026"
acceso = False          # bandera: ¿ya entró?
intentos = 0
while not acceso and intentos < 3:     # dos razones para parar
    intento = input("Contraseña: ")
    intentos += 1
    if intento == CLAVE:
        acceso = True                   # la bandera cambia
    else:
        print(f"Incorrecta. Te quedan {3 - intentos} intento(s)")
if acceso:                              # al salir, la bandera dice POR QUÉ salió
    print("🔓 Bienvenido")
else:
    print("🔒 Cuenta bloqueada")
