Listas que saben hacer cuentas

Una lista de Python guarda datos de cualquier tipo, pero no sabe hacer matemáticas con ellos: para subirle el IVA a 1000 precios necesitas un ciclo. NumPy es la librería de cálculo numérico más usada en ciencia, ingeniería, finanzas e inteligencia artificial. Su arreglo (ndarray) guarda datos de un solo tipo y aplica cada operación a todos los elementos a la vez: es lo que se llama vectorizar.

con_lista.py
precios = [12000, 45000, 8900]
con_iva = []
for p in precios:
    con_iva.append(p * 1.19)
con_numpy.py
import numpy as np
precios = np.array([12000, 45000, 8900])
con_iva = precios * 1.19          # ¡sin ciclo!

Fíjate: NumPy imprime los arreglos sin comas. shape es la forma (aquí, 3 elementos en una dimensión), dtype el tipo de los elementos (entero: en el navegador aparece int32; en tu computador probablemente int64) y size la cantidad total.

Para usar NumPy en tu computador: instálala una sola vez con pip install numpy (o py -m pip install numpy en Windows) y escribe import numpy as np al inicio de cada programa. En el laboratorio de esta lección ya viene incluida.

🏗️ Formas de crear arreglos

FunciónEjemploResultado
np.array(lista)np.array([4, 8, 15])[ 4 8 15]
np.arange(inicio, fin, paso)np.arange(0, 20, 5)[ 0 5 10 15]
np.linspace(inicio, fin, cantidad)np.linspace(0, 1, 5)[0. 0.25 0.5 0.75 1. ]
np.zeros(forma)np.zeros((2, 3))matriz 2 × 3 de 0.
np.ones(forma)np.ones(4)[1. 1. 1. 1.]
np.full(forma, valor)np.full(3, 7)[7 7 7]
arange vs linspace: arange avanza con un paso y, como range, no incluye el fin; linspace reparte una cantidad de puntos y sí incluye el fin. Para una forma de 2 dimensiones se usan paréntesis dobles: np.zeros((2, 3)).
crear.py 
import numpy as np

print(np.arange(0, 20, 5))
print(np.linspace(0, 1, 5))
print(np.zeros((2, 3)))
print(np.ones(4))
print(np.full(3, 7))

⚡ Operaciones vectorizadas

Arreglo y númeroLa operación se aplica a cada elemento: precios * 1.19, notas + 0.5, a ** 2.
Dos arreglos del mismo tamañoSe operan elemento a elemento: cantidades * precios. Si los tamaños no coinciden: ValueError.
Funciones de NumPynp.sqrt(a), np.abs(a), np.round(a, 2) también trabajan sobre todo el arreglo.
factura.py 
import numpy as np

precios = np.array([12000, 45000, 8900, 23000])
con_iva = precios * 1.19
descuento = np.where(precios >= 20000, 0.10, 0.0)   # 10 % a los de 20000 o más
final = con_iva * (1 - descuento)
print(con_iva)
print(final.round(2))
print(f"Total a pagar: {final.sum():.2f}")
[14280. 53550. 10591. 27370.]
[14280. 48195. 10591. 24633.]
Total a pagar: 97699.00
np.where(condición, valor_si, valor_no) es el "if" de los arreglos: decide elemento por elemento, sin ciclos.

🎭 Índices, slicing y máscaras

Los índices y el slicing funcionan como en las listas: a[0], a[-1], a[1:4], a[::-1]. Lo nuevo son las máscaras booleanas: una comparación como a > 25 produce un arreglo de True/False, y a[mascara] se queda solo con los elementos donde hay True.

filtros.py 
import numpy as np

temps = np.array([24.5, 19.0, 27.3, 22.1, 18.4, 29.0, 21.7])
calurosos = temps > 25                       # máscara
print(calurosos)
print(temps[calurosos])                      # solo los True
print("Días calurosos:", calurosos.sum())    # True cuenta como 1
print("Posiciones:", np.where(calurosos)[0])
print(temps[1:4], temps[::-1])
[False False  True False False  True False]
[27.3 29. ]
Días calurosos: 2
Posiciones: [2 5]
[19.  27.3 22.1] [21.7 29.  18.4 22.1 27.3 19.  24.5]
Para combinar condiciones se usan & (y) y | (o), con paréntesis: a[(a > 10) & (a < 40)]. Con and/or obtienes ValueError: the truth value of an array … is ambiguous.

import numpy as np

notas = np.array([4.5, 3.2, 5.0, 2.8, 3.9, 4.1])
print("Promedio:", notas.mean().round(2))
print("Mediana:", np.median(notas))
print("Máx:", notas.max(), "en la posición", notas.argmax())
print("Desviación:", notas.std().round(2))

Para mostrar resultados usa f-strings con formato: f"{notas.mean():.2f}". Si metes valores de NumPy en una lista de Python y la imprimes, verás algo como [np.float64(4.5)]; conviértela antes con .tolist().

🧱 Matrices con NumPy

Una matriz es un arreglo de 2 dimensiones: shape es (filas, columnas). Se accede con un solo par de corchetes: m[fila, columna], y con slicing se toman filas, columnas o submatrices: m[1], m[:, 2], m[0:2, 1:3]. Las funciones estadísticas reciben axis: axis=0 opera hacia abajo (un resultado por columna) y axis=1 hacia la derecha (uno por fila).

matriz.py 
import numpy as np

ventas = np.array([[120, 95, 140],
                   [80, 110, 100]])
print(ventas.shape)
print(ventas[1, 2])          # fila 1, columna 2
print(ventas[:, 0])          # primera columna
print(ventas.sum(axis=1))    # total por sucursal (filas)
print(ventas.sum(axis=0))    # total por mes (columnas)
print(ventas.T)              # transpuesta

✖️ Elemento a elemento vs producto matricial

matmul.py 
import numpy as np

cantidades = np.array([[2, 1, 0],
                       [0, 3, 4]])   # 2 clientes × 3 productos
precios = np.array([3500, 1200, 800])
print(cantidades * 2)                 # elemento a elemento
print(cantidades @ precios)           # total por cliente
[[4 2 0]
 [0 6 8]]
[8200 6800]

@ (producto matricial) combina cada fila con el vector: cliente 1 = 2·3500 + 1·1200 + 0·800 = 8200. Es la forma más rápida de calcular muchos totales a la vez.
