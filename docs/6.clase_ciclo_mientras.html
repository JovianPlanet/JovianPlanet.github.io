Cuando no sabes cuántas veces repetir

Con el ciclo Para repetíamos un número conocido de veces (de 1 a N). Pero, ¿cuántos intentos necesita alguien para adivinar un número? ¿Cuántos datos ingresará antes de escribir "0"? No lo sabemos de antemano. Para eso existe el ciclo Mientras: repite mientras una condición sea Verdadera.

La regla de oro del Mientras (3 partes):
  1. Antes: se prepara la variable de control.
  2. Condición: se revisa antes de cada vuelta.
  3. Actualización: dentro del cuerpo, algo cambia para que la condición, algún día, sea Falsa.
Si falta la parte 3 → bucle infinito (lo cazamos en su pestaña).

📝 Definición y sintaxis

El Mientras ejecuta un bloque repetidamente mientras una condición se cumpla. Cuando deja de cumplirse, sale del ciclo. Cada ejecución completa del bloque es una iteración. La condición se evalúa antes de cada vuelta: si al entrar ya es Falsa, el cuerpo no se ejecuta ni una vez.

Mientras condicion Hacer
    // cuerpo (instrucciones que se repiten)
    // actualización de la variable de control
FinMientras
PiezaQué es
CondiciónSe evalúa antes de cada iteración. Verdadera → ejecuta; Falsa → termina.
CuerpoLas instrucciones que se repiten.
ActualizaciónModifica la variable de la condición para que el ciclo pueda terminar.

Ejemplo base — contador con Mientras

Algoritmo ContadorMientras
    Definir contador Como Entero
    contador <- 1                    // (1) preparar ANTES
    Mientras contador <= 5 Hacer     // (2) condición
        Escribir contador
        contador <- contador + 1     // (3) actualización
    FinMientras
FinAlgoritmo
// Salida: 1 2 3 4 5

¿Cómo funciona por dentro? (diagrama)

🐍 En Python
Es la palabra while con dos puntos e indentación (no hay FinMientras): 
contador = 1
while contador <= 5:
    print(contador)
    contador = contador + 1   # ¡la actualización!

♾️ Bucle infinito

Si la condición siempre es Verdadera, el ciclo nunca termina. Casi siempre es un error (se olvidó la actualización), aunque a veces es deseable (un servidor que debe estar siempre activo).

Mientras Verdadero Hacer
    // se repite para siempre…
FinMientras
🔎 Pregúntate siempre: "¿qué instrucción del cuerpo hará que, algún día, la condición sea Falsa?" Si no hay ninguna → bucle infinito.
🐍 En Python
El infinito clásico es while True: y para salir se usa break. En PSeInt lo controlamos con una bandera que se vuelve Falsa.

🚦 Variables centinela y bandera

🎯 Variable centinela

Una variable de control que hace que el ciclo se repita hasta que su valor sea un valor "señal" (el centinela). Ideal cuando el usuario ingresa datos y un valor especial dice "ya terminé".

Algoritmo SumaConCentinela
    Definir numero, suma Como Entero
    suma <- 0
    Leer numero                      // primer dato ANTES del ciclo
    Mientras numero <> 0 Hacer       // 0 = centinela
        suma <- suma + numero
        Leer numero                  // actualización: pedir el siguiente
    FinMientras
    Escribir "Suma total: ", suma
FinAlgoritmo

Prueba: 4, 7, 9, 0 → suma = 20. El 0 no se suma; solo marca el fin.

Patrón "leer antes y al final": se lee el primer dato antes del ciclo y el siguiente al final del cuerpo, para que la condición siempre use el dato más reciente.

🚩 Variable bandera (flag)

Una variable booleana (Lógico) que controla el ciclo: se repite mientras la bandera sea Verdadera y se sale cuando pasa a Falsa. Útil cuando la salida depende de que "ocurra algo" (acertar una clave, encontrar un dato).

Algoritmo SistemaAcceso
    Definir clave, intento Como Caracter
    Definir intentos Como Entero
    Definir ok Como Logico
    clave <- "admin123"
    intentos <- 0
    ok <- Falso
    Mientras intentos < 3 Y NO ok Hacer
        Leer intento
        Si intento = clave Entonces
            ok <- Verdadero        // baja la bandera de "seguir"
        SiNo
            intentos <- intentos + 1
        FinSi
    FinMientras
    Si ok Entonces Escribir "✅ Bienvenido" SiNo Escribir "🔒 Bloqueada" FinSi
FinAlgoritmo
Centinela vs bandera: la centinela compara un valor (numero = 0). La bandera es un Verdadero/Falso que "bajas" cuando pasa algo dentro del ciclo. ¡A menudo se combinan!
🐍 En Python
ok = False
while intentos < 3 and not ok:
    ...

🎮 Adivina el número

El programa "piensa" un número del 1 al 100. Tienes 7 intentos. Es exactamente un ciclo Mientras: se repite mientras te queden intentos Y no aciertes. ¡Gana XP si lo logras!

🐍 El ciclo detrás del juego
import random
secreto = random.randint(1, 100)
intentos, acerto = 0, False
while intentos < 7 and not acerto:
    g = int(input("Adivina: "))
    intentos += 1
    if g == secreto: acerto = True
    elif g < secreto: print("más alto")
    else: print("más bajo")
