El programa aprende a decidir

Hasta ahora el programa iba en línea recta: una instrucción tras otra. Una estructura condicional es la primera bifurcación del camino: "SI se cumple esto, haz aquello."

La decisión nace de una condición que se evalúa como Verdadero o Falso (¡aquí usamos los operadores relacionales y lógicos!). En el diagrama de flujo, toda decisión es un rombo con salidas Sí y No.

1️⃣ Condicional simple

Ejecuta un bloque solo si la condición es verdadera. Si es falsa, no hace nada y sigue de largo.

Si condicion Entonces
    // instrucciones si es Verdadero
FinSi

Ejemplo — Descuento por compra grande

Algoritmo DescuentoSimple
    Definir compra, total Como Real
    Leer compra
    total <- compra
    Si compra > 100 Entonces
        total <- compra - (compra * 0.10)   // 10% desc.
    FinSi
    Escribir "Total a pagar: ", total
FinAlgoritmo
🐍 En Python
Se usa if con dos puntos; el bloque va indentado (no hay FinSi: el fin lo marca la sangría). 
if compra > 100:
    total = compra - compra * 0.10

2️⃣ Condicional doble

Elige entre dos caminos: uno si la condición es verdadera y otro si es falsa. Siempre se ejecuta exactamente uno.

Si condicion Entonces
    // camino Verdadero
SiNo
    // camino Falso
FinSi

Ejemplo — ¿Aprobó o reprobó?

Algoritmo AproboReprobo
    Definir nota Como Real
    Leer nota
    Si nota >= 60 Entonces
        Escribir "APROBADO"
    SiNo
        Escribir "REPROBADO"
    FinSi
FinAlgoritmo
🐍 En Python
El SiNo es else: 
if nota >= 60:
    print("APROBADO")
else:
    print("REPROBADO")

3️⃣ Condicional múltiple

Cuando hay más de dos caminos. Dos formas en PSeInt:

Forma A — Escalera SiNo Si (para rangos)

Ideal cuando las opciones dependen de rangos o condiciones distintas.

Si nota >= 90 Entonces
    Escribir "A"
SiNo
    Si nota >= 80 Entonces
        Escribir "B"
    SiNo
        Si nota >= 70 Entonces
            Escribir "C"
        SiNo
            Escribir "D o F…"
        FinSi
    FinSi
FinSi

Forma B — Estructura Segun (para valores exactos)

Ideal cuando comparamos una variable contra valores concretos (un menú, un día, un número de opción).

Segun opcion Hacer
    1:
        Escribir "Resultado: ", a + b
    2:
        Escribir "Resultado: ", a - b
    3:
        Escribir "Resultado: ", a * b
    De Otro Modo:
        Escribir "Opción inválida"
FinSegun
¿Escalera o Segun? Usa Segun cuando comparas igualdad contra valores exactos (1, 2, 3…). Usa la escalera cuando hay rangos o comparaciones con >, <, >=.
🐍 En Python
La escalera se escribe con elif (contracción de else if), mucho más corta que anidar. El Segun se parece a match (Python 3.10+). 
if   nota >= 90: print("A")
elif nota >= 80: print("B")
elif nota >= 70: print("C")
elif nota >= 60: print("D")
else:            print("F")

4️⃣ Condicional anidado

Un condicional dentro de otro: se plantea una segunda pregunta solo si la primera se cumplió (decisiones "en capas").

Múltiple vs anidado: la escalera múltiple elige una opción entre varias del mismo nivel. El anidado hace una segunda decisión dependiente de la primera.

Ejemplo — Clasificar un número

Algoritmo ClasificarNumero
    Definir numero Como Entero
    Leer numero
    Si numero > 0 Entonces
        Si numero MOD 2 = 0 Entonces   // anidado
            Escribir "Positivo y PAR"
        SiNo
            Escribir "Positivo e IMPAR"
        FinSi
    SiNo
        Si numero < 0 Entonces
            Escribir "Negativo"
        SiNo
            Escribir "Cero"
        FinSi
    FinSi
FinAlgoritmo
🐍 En Python
El anidamiento se ve por la sangría: cada nivel indenta más. Por eso Python es tan estricto con la indentación — es la que marca "qué está dentro de qué". 
if numero > 0:
    if numero % 2 == 0:
        print("Positivo y PAR")
    else:
        print("Positivo e IMPAR")
